Codex Aura 安装与使用说明

版本0.4.6，更新时间2026-10-08（北京时间）。macOS 14+；Universal包包含Apple芯片arm64和Intel x86_64，Intel及macOS 14实机尚未验收。需要单独安装兼容Codex并以ChatGPT账号登录；本工具不内置Codex。

Dock 图标修复：后台菜单栏位置检测不再自动显示/隐藏 Dock 图标。只有手动重新打开 App 且进入备用窗口时才显示 Dock 图标；关闭备用窗口或返回菜单栏面板后隐藏。

同步优化：额度请求最多等待25秒，整次连接最多45秒。额度更新失败时，已确认同一账号则保留本次运行中上次成功的额度并标注非实时；不同账号不复用额度。首次读取失败仍显示未知。今日统计缺失不等于零；可在“设置与关于”中自行启用本地日志补充估算。

0.4.6 菜单栏恢复：首次使用新的原生图标位置，初始化到右侧（由系统最终安排），不沿用旧版失效的位置。之后保留 Command 拖动的位置。备用窗口提供“恢复菜单栏图标”和“复制图标诊断”；诊断仅包含系统版本及图标/屏幕坐标，不含账号或用量。

macOS 26 看不到菜单栏图标：打开“系统设置 → 菜单栏 → 允许在菜单栏显示”，开启 Codex Aura，再退出并重新打开 App。出现备用窗口不一定是菜单栏空间不足；应用内“恢复菜单栏图标”不能代替此系统开关。用户已反馈在 macOS 26.5.1 开启后恢复，但不代表所有系统与多屏组合均已验收。Apple 说明：https://support.apple.com/zh-cn/guide/mac-help/mchlad96d366/26/mac/26

菜单栏恢复流程：启动时先等待系统布局，不再自动打开备用窗口；图标持续不可用时尝试一次重新注册原生图标。恢复尝试可能需要约12秒。仍不可用时可手动重新打开 App 进入备用窗口；后台不自动显示 Dock。菜单栏点击优先打开正常弹出面板。

菜单栏位置：本版移除了不跟随系统排列的悬浮备用图标，使用 macOS 原生菜单栏图标。按住 Command 拖动图标可调整顺序；系统会记住位置。不能保证固定在其他应用图标的左侧。菜单栏空间不足时，可重新打开 App 进入可拖动窗口。

核对SHA256，解压.dmg.zip得到DMG，双击打开镜像，将App拖入Applications，再打开菜单栏能量环。默认使用系统菜单栏图标，与其他图标一起排列；可按住⌘拖动，不能保证一直在最左侧。图标无法显示时可手动重新打开App进入可拖动窗口；只有备用窗口打开期间显示Dock图标。当前临时签名，没有Developer ID或已验证公证；安全提示请参考https://support.apple.com/en-us/102445，仅在确认来源和完整性后选择系统提供的操作。不要忽略恶意或损坏提示，不用清除隔离属性替代签名公证。旧安装助手已停用，也不纳入新DMG。

用量每5分钟刷新；默认不读本地会话，不访问X或Google。设置中可明确开启本地日志参考统计、X雷达、公开帖子的Google翻译；这三项默认关闭。翻译仅发送公开帖子文本，日志和账号用量不会发给作者/X/Google。Codex子进程本身按Codex的配置认证及联网。

窗口按服务返回时长标注；缺失数据显示不可用。日统计优先账号服务，缺失时可使用该账号已观测历史，启用日志后才使用本地目录估算；本地目录可能包含多个账号。美元仅为单价参考估算，不是实际账单。雷达是关键词分数，不是概率或重置承诺。点击电源按钮退出。

服务同时提供多个额度窗口时，点击窗口标签可切换主显示。每周或5小时窗口到1%及以下时，每个重置周期自动弹出一次；红色文字突出低额度。服务返回重置卡数量时显示重置卡按钮，点击查看到期明细；不消耗或使用重置卡。雷达仅判断最新帖子，不使用旧帖的高分替代新帖判断；翻译不可用时提示原因，不把英文冒充中文。
