# Security reports

Never include credentials, `auth.json`, raw session files, complete logs, cookies, account identifiers or company paths in a public report. Prefer a minimal reproduction with synthetic data and a redacted summary.

For a sensitive vulnerability, use a private contact option published by the author rather than posting secret details in an Issue. A dedicated private reporting address has not yet been established. Do not send private data to a guessed address.

The app invokes a separately installed Codex executable, so use trusted installation sources and report its version. Experimental X/translation features are off by default. Ad-hoc signature integrity does not establish Developer ID trust, notarization, or absence of vulnerabilities. Stop on malware or damaged-app warnings and consult Apple's guidance.
