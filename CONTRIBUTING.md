# Contributing

Thanks for helping improve Codex Aura. This project is source-available under PolyForm Noncommercial 1.0.0; read LICENSE and NOTICE before contributing or distributing it.

Use focused changes with a concrete problem and validation. Include macOS / architecture / Codex version when reporting compatibility issues. Tests must use synthetic account responses and session fixtures: do not launch a real account or include real credentials, sessions, company code or private paths.

Run `swift test --jobs 2` with enough disk space. App runtime and release packaging are separate acceptance steps. Do not disable Gatekeeper or remove quarantine to make validation pass. Preserve existing third-party notices and identify the origin and license of new assets or code. Do not submit material you lack permission to share.

Contributors retain rights to their additions; a contribution does not automatically give CC ownership or separate commercial relicensing rights. Any such grant requires an explicit agreement. No commercial authorization is implied by this guide.
